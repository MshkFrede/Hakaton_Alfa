# Скоринг и кредитная политика

Решение принимается в два независимых шага:

1. **Скоринг** ([`internal/scoring`](../internal/scoring/scorecard.go)) оценивает **риск заёмщика**: балл 0–1000, рейтинг A–D, стоп-факторы. Сумма и срок кредита в балл не входят.
2. **Кредитная политика** ([`internal/policy`](../internal/policy/policy.go)) по баллу и параметрам заявки определяет **исход и условия**: ставку, допустимую сумму, контрпредложение, нужен ли специалист.

Так одна и та же оценка риска даёт разные решения для разных продуктов и сумм. Модель можно перекалибровать, не меняя правил банка.

> Все пороги и веса иллюстративные, подобраны под синтетические данные. Это не методика банка.

## Скоринговая карта `scorecard-v1`

Базовый балл **500**, к нему прибавляются вклады факторов.

| Фактор | Источник | Условие → баллы |
|---|---|---|
| Возраст бизнеса | ЕГРЮЛ | < 3 мес. → −80 (+ стоп-фактор) · < 1 года → −60 · 1–3 года → 0 · 3–5 лет → +40 · > 5 лет → +70 |
| Длина кредитной истории | БКИ | нет → −20 · < 2 лет → 0 · ≥ 2 лет → +40 |
| Просрочки за 12 мес. | БКИ | нет → +60 · ≤ 30 дн. → −40 · ≤ 90 дн. → −120 · > 90 дн. → −200 |
| Текущая просрочка | БКИ | есть → −100 |
| Запросы КИ за 30 дней | БКИ | 3–4 → −20 · ≥ 5 → −50 |
| Заявленная выручка vs ФНС | ФНС + анкета | заявлено > отчётности на 30%+ → −60 · иначе +20 |
| Налоговая задолженность | ФНС | есть → −80 |
| Адрес массовой регистрации | ФНС | да → −40 |
| Массовый руководитель | ФНС | да → −40 |
| Текущая долговая нагрузка | БКИ + анкета | < 10% выручки → +40 · 10–25% → 0 · 25–40% → −60 · > 40% → −120 |
| Обеспечение | анкета | есть → +40 |

**Рейтинг:** A ≥ 700, B ≥ 600, C ≥ 500, D < 500. Иллюстративная PD: A 1%, B 3%, C 7%, D 15%.

**Стоп-факторы** (отказ независимо от балла): компания не действует по ЕГРЮЛ; бизнесу меньше 3 месяцев; текущая просрочка более 90 дней; налоговая задолженность более 1 млн ₽; руководитель дисквалифицирован.

**Консервативность:** для расчёта нагрузки берётся меньшая из выручек (заявленной и отчётной ФНС) и большая из сумм текущих платежей (заявленной и по данным БКИ).

**Объяснимость:** каждый фактор сохраняется с названием, значением и вкладом. Специалист видит разбивку баллов. Для клиента у фактора есть отдельная формулировка `client_hint` («Высокая текущая долговая нагрузка»), которая не раскрывает веса модели.

## Кредитная политика

Правила применяются по порядку:

| # | Правило | Результат |
|---|---|---|
| 1 | Есть стоп-фактор | **Отказ** |
| 2 | Расчёт: ставка = базовая ставка продукта + надбавка за рейтинг (A 0, B +1,5, C +3, D +5 п.п.); платёж — аннуитет; нагрузка = (текущие платежи + новый) / месячная выручка | — |
| 3 | Балл < 420 | **Отказ** |
| 4 | Нагрузка ≤ 30% | рекомендация **одобрить** на запрошенных условиях |
| 4′ | Нагрузка > 30% | рекомендация **контрпредложение**: сначала увеличить срок (шагом 6 мес. до максимума продукта), иначе уменьшить сумму до максимально допустимой на максимальном сроке (округление до 10 000 ₽). Если не проходит даже минимальная сумма продукта — рекомендация **отказ** |
| 5 | Нужен ли специалист: нет данных хотя бы из одного источника; рейтинг C или D; продукт без автоодобрения (инвесткредит); сумма выше лимита автоодобрения продукта; система рекомендует отказ из-за нагрузки (не по стоп-фактору) | **Ручной разбор** с рекомендацией системы |
| 6 | Иначе | Рекомендация становится **автоматическим решением** |

Исключение из п. 5: рейтинг D при полных данных и рекомендации «отказ» — автоматический отказ, без загрузки специалиста.

## Продукты

| Продукт | Сумма | Срок | Базовая ставка | Автоодобрение |
|---|---|---|---|---|
| Экспресс-кредит | 0,1–5 млн ₽ | 3–24 мес. | 23% | до 5 млн ₽ |
| Оборотный кредит | 0,5–30 млн ₽ | 6–36 мес. | 19% | до 10 млн ₽ |
| Инвестиционный кредит | 1–100 млн ₽ | 12–84 мес. | 17% | нет, всегда специалист |

## Подбор продукта под задачу

Клиент выбирает не продукт, а **задачу бизнеса**. Система ранжирует продукты по приоритету для задачи и отсекает неподходящие по сумме, объясняя почему.

| Задача | Приоритет продуктов |
|---|---|
| Купить оборудование или транспорт | Инвестиционный → Экспресс |
| Закупить товар или сырьё | Оборотный → Экспресс |
| Закрыть кассовый разрыв | Экспресс → Оборотный |
| Подготовиться к сезону | Оборотный → Экспресс |
| Запустить новое направление | Инвестиционный → Оборотный |
